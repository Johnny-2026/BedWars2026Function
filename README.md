## BedWars2026
#### 基于BedWars1058的国内优质起床战争玩法拓展插件

## 获取方法
1.  安装插件加载器以及依赖
2.  在官网为您的服务器添加令牌
3.  编辑需要的语言文件`/plugins/BedWars1058/Languages/messages_xxx.yml`
4.  启动服务器
